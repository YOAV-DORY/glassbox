# Glassbox (live demo)

An explainable credit-risk model: probability of default, a cost-based approve/decline policy,
SHAP reason codes, a portfolio simulator and a fairness audit.

**This demo runs a model trained on synthetic applicants** (generated in code), so every number
in it is illustrative. The real model, results, fairness findings and limitations, trained on the
public Home Credit dataset, are documented in the GitHub repository:
https://github.com/YOAV-DORY/glassbox

A student portfolio project, not a lending product.
